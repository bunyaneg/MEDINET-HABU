# MEDINET-HABU — Bunyan

A bilingual (Arabic / English), responsive introductory exploration of the mortuary temple of Ramesses III at Medinet Habu, Luxor.

## Run locally
Open `index.html` in a modern browser. The project is static and has no build step or external JavaScript dependencies.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**, then Save.
4. After GitHub finishes deployment, the site will be available at:
   https://bunyaneg.github.io/MEDINET-HABU/

## Included in this first version
- Arabic-first interface with English language toggle.
- Responsive landing page and guided sequence of architectural stops.
- Image gallery linking to original Wikimedia Commons file/category pages.
- Browser text-to-speech for the selected stop.
- Fullscreen control and scroll progress indicator.

## Scope note
This is an introductory guided-tour prototype, not a 360° panorama or a 3D reconstruction. The current route follows the broad sequence published by the Ministry of Tourism and Antiquities. Detailed relief-by-relief interpretation, verified scene photographs, and any true panoramic capture should be added only after specialist review and source verification.
